# HU01 – Cadastro Pessoal, de Marca e Celebridade
**Como**: usuário comum, administrador, marca de roupa ou celebridade  
**Posso**: realizar cadastro pessoal, de marca ou de celebridade  
**Para**: acessar meus recursos dentro do aplicativo  

## Critérios de Aceitação

- CA-1 CADASTRO BEM-SUCEDIDO
  - **Dado que**: o usuário informa corretamente todos os dados obrigatórios
  - **Quando**: solicita o cadastro
  - **Então**: o sistema realiza o registro e confirma a criação da conta

- CA-2 CADASTRO COM DADOS OBRIGATÓRIOS AUSENTES
  - **Dado que**: o usuário não preenche todos os dados obrigatórios
  - **Quando**: solicita o cadastro
  - **Então**: o sistema informa os campos pendentes e não conclui o registro

- CA-3 CADASTRO COM EMAIL JÁ EXISTENTE
  - **Dado que**: o usuário informa um email já cadastrado no sistema
  - **Quando**: solicita o cadastro
  - **Então**: o sistema bloqueia o novo registro e orienta a realizar autenticação ou recuperação de acesso

- CA-4 SELEÇÃO DE TIPO DE PERFIL
  - **Dado que**: o usuário está no formulário de cadastro
  - **Quando**: seleciona o tipo de conta (pessoal, marca ou celebridade)
  - **Então**: o sistema exibe os campos específicos para aquele tipo de perfil

- CA-5 CADASTRO DE MARCA REQUER APROVAÇÃO
  - **Dado que**: o usuário seleciona "Marca" como tipo de perfil
  - **Quando**: completa o cadastro com dados da marca (nome, CNPJ, categoria, website)
  - **Então**: o sistema registra a marca em status "Pendente de Aprovação" e notifica administradores

- CA-6 CADASTRO DE CELEBRIDADE REQUER APROVAÇÃO
  - **Dado que**: o usuário seleciona "Celebridade" como tipo de perfil
  - **Quando**: completa o cadastro com dados de identidade (nome artístico, seguidores/verificação, áreas de interesse)
  - **Então**: o sistema registra a celebridade em status "Pendente de Aprovação" e notifica administradores

- CA-7 VALIDAÇÃO DE DOCUMENTO PARA MARCA E CELEBRIDADE
  - **Dado que**: o usuário é marca ou celebridade
  - **Quando**: tenta cadastrar seu perfil
  - **Então**: o sistema solicita e valida documento comprobatório (CNPJ para marca, RG/RNE/comprovante de seguidores para celebridade)
